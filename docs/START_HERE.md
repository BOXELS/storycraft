# Start here

This is **cursor-rules-rea** — the only template. Same idea as cursor-rules, but for official REA.

1. Click **Use this template** on [BOXELS/cursor-rules-rea](https://github.com/BOXELS/cursor-rules-rea), or copy the `.cursor/` files into a folder.
2. Open that folder in Cursor.
3. Type `/start-investigation` and say what you want to inspect.

If the agent says REA is not connected, let it run (or paste) `npx rea-agents@latest setup --client cursor`, then restart Cursor. That is how this computer gets current REA.

Allowed uses: [AUTHORIZATION.md](AUTHORIZATION.md).
